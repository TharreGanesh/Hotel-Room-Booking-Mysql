Hotel Room Booking System – MySQL

Project Overview

This project is a Hotel Room Booking System developed using MySQL. It demonstrates database design, SQL queries, stored procedures, triggers, sample data management, and data analytics.

Technologies Used

- MySQL
- MySQL Workbench
- SQL

Project Files

File| Description
"01_schema.sql"| Database schema and table creation
"02_procedures_triggers.sql"| Stored procedures and triggers
"03_seed_data.sql"| Sample data insertion
"04_analytics.sql"| Analytical SQL queries

How to Run Locally

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench and connect to your database server.
3. Open and execute "01_schema.sql".
4. Open and execute "02_procedures_triggers.sql".
5. Open and execute "03_seed_data.sql".
6. Open and execute "04_analytics.sql".
7. Verify the results using SQL queries.

Project Objectives

- Understand relational database design.
- Practice SQL queries and database operations.
- Implement stored procedures and triggers.
- Insert and manage sample data.
- Perform database analytics.
